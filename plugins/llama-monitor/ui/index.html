Set up host telemetry
  1. Download the collector bundle and setup guide from Admin → Plugins → Companion services.
  2. Install it on the monitored Linux machine. Use the physical host for physical RAM readings.
  3. Provision a dedicated bearer credential and configure the private listener as described in the guide.
  4. Create an approved GET connection to /telemetry in Secrets → Connect API and add its exact path to plugin connection grants.
  5. Select this engine, enter that connection name above, save, then Read once.

Bundle includes Python collector, systemd unit and explicit installer. Nothing installs automatically. Linux/AMD supported; unsupported counters remain unavailable. Process RSS needs an explicit PID.
