# keys/

The **public** halves of the marketplace's signing keys. Nothing secret is
ever in this directory, or anywhere in this repository (`*.key` is ignored).

| File | What it is |
|---|---|
| `octipus.pub` | The marketplace publisher key. Every package version and every `index.json` on plugins.octipus.cc is signed with its private half, on the publishing machine. |
| `octipus-backup.pub` | The backup key. Its private half is kept **offline** (a password manager, or a USB stick in a drawer) and never signs packages. If the active key is lost or leaks, the backup signs an index whose `revoked` list names the old key and starts the new one. |

Both public keys ship in Octipus's built-in `trustedPublishers` entry for the
marketplace (publisher `Octipus`), so a host keeps working through a key
rotation without an update.

The key holder adds these two files (see "Publishing" in the
[README](../README.md)); they are not generated by any script here.
`npm run publish` refuses to run without them, verifies every package
signature against `octipus.pub`, and verifies the index against both. It
also copies them to `/keys/` on the site, for admins setting up the registry
by hand; the trust anchor is this directory and Octipus's built-in entry,
not the copy on the web server.

To revoke a key, add `{ "keyId": "ed25519:<64 hex>", "reason": "…" }` to
`keys` in [`revoked.json`](../revoked.json) and publish with the other key.
